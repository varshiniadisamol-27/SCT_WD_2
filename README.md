# ⏱️ SkillCraft Stopwatch Web Application

This project was created as part of my **SkillCraft Technology Web Development Internship (Task 2)**.

## 📌 About the Project
The Stopwatch Web Application helps users measure time accurately and record lap times. It is designed with a clean and interactive user interface and supports multiple themes for a better user experience.

## ✨ Features
- Start the stopwatch
- Pause the stopwatch
- Reset the stopwatch
- Record lap times
- Theme switching (Dark, Light, and Purple)
- Responsive design for mobile and desktop
- Smooth animations and modern UI

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 🚀 How to Use
1. Click **Start** to begin the timer.
2. Click **Pause** to stop the timer temporarily.
3. Click **Reset** to set the timer back to zero.
4. Click **Lap** to save the current time.
5. Use the theme buttons to switch between different themes.
